# Model weights

Download the five NPAM fold weights from the GitHub release and place them in this directory:

- `fold_0_best_auc.pth`
- `fold_1_best_auc.pth`
- `fold_2_best_auc.pth`
- `fold_3_best_auc.pth`
- `fold_4_best_auc.pth`

The inference script averages the five fold-specific positive-class scores.
